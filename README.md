# Order Management System

A clean and simple Python terminal application designed for order management with unique IDs.

## 🚀 About the Project
This is my **very first independent programming project**, created on my **second day** of learning Python from complete scratch. 

I designed the system architecture, built custom functions for each process, and handled dynamic memory updates (adding and removing dictionaries inside a global database list). I also solved the duplicate naming issue by implementing an automated **Unique Order ID** tracker.

*Note: This is a pet project built entirely for educational purposes to master Python fundamentals (Variables, Control Flow, Lists, Dictionaries, While/For Loops, and Functions).*

## 🛠️ Features
- **Add Orders**: Saves food/item choices inside a persistent database with auto-incremented IDs.
- **View Orders**: Checks if the kitchen queue is empty and displays all active orders.
- **Deliver Orders**: Searches the database for a specific ID, removes it upon completion, and prevents crashes via a flag validation check.
- **Error Handling**: Full protection against unknown menu entries and invalid user inputs.

## 💻 Tech Stack
- **Language**: Python 3.x
- **Concepts used**: Functions (`def`), Global Variables (`global`), Loops (`while`, `for`), Lists (`[]`), Dictionaries (`{}`), Flags, Error-catching.
